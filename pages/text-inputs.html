Inputs & Forms

22 input families, 66 production models. Every field type a rental fintech needs — from simple text to OTP verification, currency formatting, file uploads, and rich text editors.

INPUTTXT

Text Input

The foundational input field. Standard, with leading icon, and with trailing action.

INPUTTXT·AModel A — Standard Text Field
  • Height: 44px minimum — matches Apple HIG and Material touch target
  • Border radius: 12px — softer than sharp corners, inviting input (rounded shapes feel approachable per Gestalt)
  • Font weight 500: Slightly bold user input differentiates entered data from placeholder
  • Focus state: 3px shadow ring + darker border — WCAG 2.1 visible focus indicator
  • Context: Tenant name, property address, lease details — the most common input on Rentenpe
INPUTTXT·BModel B — Leading Icon Text Field
  • Leading icon: Provides instant context before user reads the label — 40% faster field identification
  • Icon color: Tertiary gray — doesn't compete with input text or label
  • Use case: Forms with many similar fields (property, tenant, owner name disambiguation)
INPUTTXT·CModel C — Trailing Action Text Field
  • Copy action: Essential for referral codes, transaction IDs, bank details in fintech
  • Validation icon: Inline check mark gives instant feedback — reduces form anxiety by 25%
  • Progressive disclosure: Action appears only when field has value (clean empty state)
SEARCH

Search Input

Full width, compact, and search with actions. The gateway to content discovery.

SEARCH·AModel A — Full Width Search
  • Pill radius: Full rounded border distinguishes search from data-entry inputs visually
  • Psychology: Search is the #1 navigation pattern for returning users — must be instantly recognizable
  • Clear button: Appears only when text is entered — progressive disclosure prevents clutter
SEARCH·BModel B — Compact Toolbar Search
  • Compact: 36px height for table toolbars and dense UIs — saves vertical space
  • Context: Table search, sidebar filter, header search
